## ملخص الاستراتيجية

### المؤشرات المستخدمة
| المؤشر | الوظيفة |
|--------|---------|
| SuperTrend | تحديد الاتجاه العام |
| Parabolic SAR | نقاط الدخول والخروج |
| MACD | تأكيد الزخم |
| EMA 5/10/20 | المتوسطات المتحركة |
| RSI | مقياس الزخم |
| Bollinger Bands | القناة السعرية |
| أنماط الشموع | إشارات الانعكاس |
| الدعم والمقاومة | نقاط الدخول القوية |

### قواعد الدخول
1. لا تدخل في القمم أو القيعان
2. انتظر تأكيد المؤشرات المتعددة
3. تأكد من الحجم
4. استخدم تحليل متعدد الفريمات (M1, M5, M15)

### إدارة المخاطر
1. عند +20 pip: SL → Breakeven + 5
2. عند +40 pip: SL يتتبع خلف السعر
3.وزّع الصفقات على10 نقاط دخول
4. لا تفتح أكثر من 10 صفقات
